# Site Voltiz Energy Gum

Page unique, en HTML, CSS et JavaScript, sans outil à installer. Publiée gratuitement avec GitHub Pages.

- **Textes** : tout est dans `index.html`, section par section (chaque bloc est commenté). Cherche `[À COMPLÉTER]` pour trouver ce qu'il reste à remplir.
- **Images** : remplace les fichiers dans `assets/` en gardant le même nom (le sachet existe en 3 tailles : `sachet-recto.webp`, `-480`, `-420` ; `og-voltiz.jpg` est l'image des liens partagés).
- **Couleurs et polices** : modifie seulement les variables en haut de `css/style.css` (bloc `:root`).
- **Commandes** : crée un formulaire gratuit sur formspree.io avec ton adresse e-mail, puis colle son lien dans `ORDER_ENDPOINT`, en haut de `js/main.js` (avant ça, remplis la déclaration de protection des données). Prix et quantité maximum se règlent juste en dessous.
- **Mise en ligne** : GitHub Pages publie la branche choisie dans Settings > Pages. Chaque modification poussée sur cette branche est en ligne en une à deux minutes, à l'adresse https://bbnate-e.github.io/Voltiz-website/
- **Polices** : Saira (licence SIL OFL, `fonts/OFL-Saira.txt`). **Icônes** : Phosphor Icons (licence MIT).
